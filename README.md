# trainsim4
**A lightweight train performance simulation tool written in Python**

**trainsim4** is a lightweight, Python-based train performance simulation tool for research, educational and recreational purposes.
This project provides a platform for exploring train dynamics and railway operation through numerical simulation.
## Features
- Train performance simulation
- Train configuration
- Route configuration and reversed route generation
## Environment requirements
- Python 3.8 or later
- Additional Python dependencies, including `pandas`
- `tkinter` support for file and directory selection
## Usage
Start the program with:

```python main.py```

Follow the interactive prompts to select the desired operation and provide the required data.
## Disclaimer
This project is intended for research, educational and recreational use only. It is not designed, validated or certified for safety-critical, production, operational or regulatory proposes.

Simulation results are subject to modal assumptions, numerical approximations and input data quality. They should not ba relied upon for real-world railway operations, safety assessments, infrastructure design or regulatory compliance.
